# 🌐 noVNC Private Browser

Ek **private noVNC browser** jo email/password login ke saath aata hai, user ki **saari activity (history, cookies, logins)** permanently save karta hai — chahe user 5 din baad wapas aaye — aur ise **Python se bhi control** kiya ja sakta hai (Selenium/Playwright via CDP).

---

## ✨ Features

- 🔐 **Email/Password Login** — noVNC web interface par authentication
- 💾 **Persistent Activity** — Browser history, cookies, bookmarks, logins sab save rehte hain
- 🐍 **Python Control** — Selenium/Playwright ke zariye programmatic control (CDP bridge)
- 🐳 **Docker-based** — Ek command se pura setup
- 🔄 **Restart-safe** — Container band/restart karne par bhi data safe
